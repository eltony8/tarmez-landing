# صفحة ترميز التسويقية

صفحة هبوط لترميز، معمولة HTML وCSS وJavaScript عادي، من غير أي build. معمولة عشان تترفع على **GitHub Pages** ببلاش.

الفولدر ده **منفصل عن كود الموقع**، فمش هيتسلّم للزباين مع المشروع.

## الملفات

| الملف | فيه إيه |
|---|---|
| `index.html` | هيكل الصفحة |
| `css/style.css` | الشكل |
| `js/config.js` | **الحاجات اللي هتغيرها:** رقم الواتساب، والإيميل، وFormspree، والأسعار، ورابط الكود |
| `js/i18n.js` | كل كلام الصفحة، عربي وإنجليزي |
| `js/main.js` | تبديل اللغة، ومشهد الكود في الأول، والتابات، والأسعار، والفورم، وفيديوهات الحملة |
| `assets/` | الشعار، والفيديوهات المضغوطة (تسجيلات حقيقية من النظام)، وصورها الثابتة |

## قبل النشر: عدّل `js/config.js`

1. **`siteUrl`:** الرابط اللي الكود اللي في أول الصفحة بيفتحه.
2. **`whatsapp`:** الرقم أرقام بس، بالصيغة الدولية، زي `9665XXXXXXXX`.
3. **`email`:** الإيميل اللي الطلبات بتوصله.
4. **`formspreeId`:** عشان الفورم يبعت الطلبات على إيميلك.
   1. اعمل حساب مجاني على formspree.io.
   2. اعمل New Form.
   3. خد الكود اللي بعد `formspree.io/f/` وحطه هنا.
   - لو سبته فاضي، زرار الإرسال هيفتح واتساب (أو الإيميل) والبيانات مكتوبة جاهزة.
5. **`plans`:** أسماء الخطط والأسعار والمميزات، عربي وإنجليزي.
   - `yearly` هو السعر الشهري لما الاشتراك يتدفع سنوي.
   - **لما الأسعار تبقى نهائية، خلّي `pricesAreDraft: false`** عشان تختفي جملة «الأسعار مبدئية».

لو الواتساب والإيميل فاضيين، زراريهم مش هيظهروا.

## تجربتها على جهازك

```bash
python -m http.server 8090
```

وبعدين افتح http://127.0.0.1:8090

## الرفع على GitHub Pages

1. اعمل ريبو جديد على GitHub، مثلًا `tarmez-landing`.
2. من جوه الفولدر ده (الريبو المحلي جاهز ومعمول فيه أول commit):

```bash
git remote add origin https://github.com/USERNAME/tarmez-landing.git
```

```bash
git push -u origin main
```

3. في الريبو على GitHub: افتح **Settings**، وبعدين **Pages**. في **Source** اختار **Deploy from a branch**، والفرع `main`، والفولدر `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو اتنين الصفحة هتشتغل على `https://USERNAME.github.io/tarmez-landing/`.
5. **دومين خاص (اختياري):** من نفس صفحة Pages حط الدومين في **Custom domain**، وظبط الـ DNS عند مزوّد الدومين على حسب تعليمات GitHub.

## ملاحظات

- **كل الشاشات والفيديوهات تسجيلات حقيقية من النظام** على بيانات تجريبية.
  - فيديوهات الحملة مصغّرة من `D:\tarmez\tarmez-campaign\output\campaign`.
  - صوت الحملة لسه بنسخة التجربة (edge-tts). لما يتعمل بـ Azure، بدّل ملفات `assets/video/reel-*.mp4`.
- **قسم الأسئلة بيقول الحقيقة:**
  - مفيش دفع إلكتروني لسه.
  - مفيش ربط مباشر مع منصة «فاتورة».
  - لما الحاجات دي تتعمل، عدّل الإجابات في `js/i18n.js`.
- **مكتبة رسم الكود (qrcode-generator) بتتحمّل من cdnjs.** لو ما اتحمّلتش، الصفحة بتشتغل عادي من غير مشهد تفكيك الكود.
- **الصفحة مراعية:**
  - تقليل الحركة عند اللي مفعّلين الإعداد ده؛
  - التنقل بالكيبورد؛
  - مقاسات الموبايل.
